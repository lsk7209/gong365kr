# 전남 2026 기업 지원사업 공고 콘텐츠 보강 브리프

## 상태와 범위

- 상태: 비발행 T3 편집 브리프. 코드, 제목, 본문, DB, 크론, 배포를 변경하지 않는다.
- 근거: `multi-dashboard` 2026-07-27 스냅샷에서 `gong365.kr`은 최근 30일 GSC 2,894 노출, 31 클릭, CTR 1.07%, 평균 게재순위 8.13이다.
- 페이지·쿼리 근거: `/regions/jeonnam` + `전남 2026 기업 지원사업 공고`, 68 노출, 0 클릭, 평균 게재순위 7.93 (2026-06-28~07-26).
- 제약: 현재 라이브 제목과 설명은 핵심 쿼리와 일치한다. 제목 교체를 먼저 하지 않고, 검색 결과에서 약속한 “어떻게 찾고 신청 판단을 하는지”를 본문에서 더 분명히 한다.

## 페르소나

### 사이트 페르소나

- 역할: 공고를 재가공해 단정하지 않고, 예비창업자와 초기 기업이 원문 공고로 안전하게 이동하도록 돕는 지원사업 탐색 가이드.
- 독자: 전남 소재 또는 전남 사업장을 검토 중이며, 공고를 많이 보지만 자격·마감·지원 형태를 빠르게 걸러야 하는 예비창업자와 초기 중소기업.
- 신뢰 원칙: 자격, 금액, 마감일은 페이지의 요약이 아니라 원문 공고를 최종 기준으로 안내한다. 확인되지 않은 지원 규모·선정 가능성·마감 연장은 쓰지 않는다.
- 금지: “무조건 선정”, “지원금 보장”, 최신성 미확인 수치, 광고성 CTA, 공고와 무관한 키워드 확장.

### 최적화 페르소나

1. 사실 정확성과 공고 원문 확인
2. 독자가 다음 행동을 정할 수 있는지
3. 제목/설명/본문의 의도 일치
4. 읽기 흐름을 해치지 않는 내부 이동

## 권장 보강안

대상은 `/regions/jeonnam` 한 페이지이며, 아래 항목은 초안 검토 후에만 적용한다.

1. H1 아래에 2~3문장짜리 **이용 기준 안내**를 둔다.
   - 이 페이지가 전남 관련 공고를 찾는 출발점임을 밝힌다.
   - 지역 소재지·사업장 조건, 접수 마감, 지원 형태를 원문에서 다시 확인해야 함을 명시한다.
2. 기존 3개 가이드 블록을 독자가 바로 판별할 수 있는 순서로 정리한다.
   - `소재지·사업장 조건` → `신청 대상과 업력` → `마감·제출서류`.
   - 각 블록은 일반 원칙까지만 설명하고, 특정 공고의 자격을 일반화하지 않는다.
3. FAQ 2개를 다음 질문으로 보강 또는 교체한다.
   - `전남에 거주하지만 사업장은 다른 지역이면 신청할 수 있나요?`
   - `마감일 전에 어떤 서류와 업력 기준을 먼저 확인해야 하나요?`
   답변은 “공고마다 다르며 원문 확인이 필요하다”는 경계를 유지하고, 확인 순서를 제시한다.
4. 공고 목록 위에 **3단계 확인 흐름**을 추가한다.
   - ① 현재 모집 여부 → ② 소재지·업력·업종 조건 → ③ 원문 공고의 서류·마감.
5. 내부 이동은 독자 행동에 맞게 제한한다.
   - 전체 공고 필터(`/programs?region=jeonnam`)는 목록 탐색용.
   - 자격 적합도 체크(`/check`)는 조건 판단용.
   - 두 링크 외에는 근거 없는 블로그 링크를 추가하지 않는다.

## 적용 전 검증

- 깨끗한 복제본에서만 변경한다. `D:\web\gong365kr`의 더티 워크트리는 사용하지 않는다.
- 제목, canonical, robots, sitemap, 기존 공고 목록·필터 동작은 유지한다.
- 데이터베이스와 크론 수집 결과를 본문에 고정 값으로 복사하지 않는다.
- 변경 후 모바일/데스크톱에서 H1, FAQ, 공고 목록, 두 내부 링크, canonical을 확인한다.
- 배포는 별도 승인과 가역적 커밋 이후에만 한다.
